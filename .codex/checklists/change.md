# Change checklist

- [ ] Based on current `develop` using a dedicated branch
- [ ] Scope is small and reviewable
- [ ] No credentials, destructive cloud actions, or unsafe defaults
- [ ] New dependencies are necessary, maintained, and pinned
- [ ] Architecture and operational docs match changed behavior
- [ ] All applicable `make` validations passed
- [ ] Changed files, assumptions, tests, and risks are reported
- [ ] Conventional Commit title is valid
