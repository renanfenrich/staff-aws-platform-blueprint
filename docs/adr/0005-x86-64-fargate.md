# ADR 0005: Start Fargate tasks on X86_64

- Status: Accepted
- Date: 2026-07-27

## Context

Fargate supports X86_64 and ARM64. ARM64 can offer better price-performance for
some workloads, but it requires a proven architecture-specific build, scan,
attestation, and runtime path. The current local and GitHub-hosted build path is
X86_64 and no image publication workflow exists yet.

## Decision

Explicitly select Linux on X86_64 for the first sandbox task definition. Keep
the cost-conscious task size at 0.25 vCPU and 0.5 GiB.

## Consequences

The first image pipeline can use the native architecture of the existing CI
runner without adding cross-build complexity. The choice may leave ARM64
savings unrealized. Reconsider after the build-once workflow can produce,
scan, attest, and benchmark ARM64 or multi-architecture images by digest.
